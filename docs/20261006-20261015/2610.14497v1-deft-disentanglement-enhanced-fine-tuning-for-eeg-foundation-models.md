## 摘要
脑电基础模型（EFMs）通过将大规模多被试预训练中的知识迁移到下游任务，提升了脑电表征学习。然而，其预训练嵌入往往保留大量与被试相关的变异，给下游分类器带来额外负担，尤其是在跨被试场景中。为解决这一问题，我们提出解耦EFM微调（DEFT），一种用于EFM微调的即插即用适配器。DEFT 促使将预训练 token 分支解耦为面向任务的内容和与被试一致的风格，然后从内容分支进行下游预测。它通过递归高斯细化、时间方差正则化、被试感知对比学习和重建来实例化这种“先分解后分类”的设计。在多个脑电数据集和四个EFM主干网络上的实验表明，DEFT 优于匹配的微调基线。进一步的消融和分析支持了预期的内容/风格分支组织。

## Abstract
EEG foundation models (EFMs) have improved EEG representation learning by transferring knowledge from large-scale multi-subject pretraining to downstream tasks. However, their pretrained embeddings often retain substantial subject-related variation, placing an additional burden on the downstream classifier, especially in cross-subject settings. To address this issue, we propose Disentangled EFM Fine-Tuning (DEFT), a plug-and-play adapter for EFM fine-tuning. DEFT encourages branch disentanglement of pretrained tokens into task-oriented content and subject-consistent style, then performs downstream prediction from the content branch. It instantiates this factorize-before-classify design with recursive Gaussian refinement, temporal-variance regularization, subject-aware contrastive learning, and reconstruction. Experiments across multiple EEG datasets and four EFM backbones show that DEFT improves matched fine-tuning baselines. Further ablations and analyses support the intended content/style branch organization.

## 1. 核心问题与研究动机

- **背景**：脑电基础模型（EEG Foundation Models, EFMs）通过大规模多被试预训练学习可迁移表征，已成为下游 EEG 任务（情绪识别、运动想象、睡眠分期、工作负荷、语音解码、抑郁分类等）的主流范式。
- **核心问题**：论文通过探测实验发现，EFM 预训练嵌入反而**放大了被试身份信息**——线性探测从预训练嵌入中恢复被试身份的准确率高于原始 EEG，而类别标签的可探测性仅小幅提升。这意味着预训练 token 空间中被试相关结构比任务相关结构更"突出"。
- **后果**：在跨被试场景下，下游分类头必须先用容量去"折扣"这些易于利用但与决策规则不对齐的被试线索，才能学到类别判别信息，导致表征"丰富但错位"，削弱跨被试鲁棒性。
- **整体含义**：论文将预训练 token 空间形式化为混合表征 $Z \to (C, S)$，其中 $C$ 为任务内容 token，$S$ 为被试风格 token，提出"先分解、后分类"（factorize-before-classify）的适配思路，把更强的被试结构提前吸收到显式分支中，使预测头无需独自解决完整混合。

## 2. 方法论

### 2.1 核心思想
- DEFT 是一个**骨干网络之后的即插即用适配器**（post-backbone adapter），在预训练 token 与预测头之间插入分解步骤，将混合 token 组织为**任务内容分支**与**被试风格分支**，仅用内容分支做下游预测。
- 内容/风格是**由训练目标诱导的功能性分支角色**，而非严格的因果因子：内容保留标签相关脑状态结构及其时间变化；风格收集以被试身份组织的试次稳定残差结构。

### 2.2 关键技术细节与流程

1. **窗口压缩与分支生成**
   - 对 token 张量 $Z \in \mathbb{R}^{M \times W \times D}$ 沿潜在通道组维度求均值，得到窗口级序列 $\bar{Z} \in \mathbb{R}^{W \times D}$。
   - 递归高斯解耦器 $G_{dis}$ 将 $\bar{Z}$ 映射为窗口级 $(C_{win}, S_{win})$，再通过**残差重注入**（$z^c_{m,w} = (z_{m,w} - \bar{z}_w) + c_w$）回到原 token 网格，保留通道组信息。

2. **递归高斯解耦器（Recursive Gaussian Disentangler, RGD）**
   - 借鉴 Xi-vector 与卡尔曼滤波的精度加权线性高斯聚合思想：每步用**对偶分支估计减除后的观测** $\tilde{e}_w = e_w - \gamma_w r_w$（$\gamma_w \in (0,1)$ 为可学习门控）替代原始混合观测。
   - 高斯融合后验：$h_w = (\Pi_w + \tilde{\Lambda}_w)^{-1}(\Pi_w T_w h_{w-1} + \tilde{\Lambda}_w \tilde{e}_w)$，其中观测精度 $\Lambda_w = \text{diag}(\exp(f_\lambda(\bar{z}_w)) + \epsilon)$ 按 token 维度自适应（应对伪迹、电极接触、非平稳活动）。
   - **非对称转移**：风格分支用静态转移 $T_w = I$；内容分支用数据依赖的动态转移 $T_w = \sum_n \alpha_{w,n} G_n$（可学习转移基的软混合）。
   - 执行**四步交替推断**：先粗估风格→再粗估内容→用内容估计精修风格→用风格估计精修内容。

3. **内在时间方差约束**
   - 方差排序损失：$L_{ord} = \max(0, m + \text{Var}(S) - \text{Var}(C))$，铰链项为零当且仅当内容方差比风格方差大出边距 $m$。
   - 风格稳定性损失：$L_{sty} = \text{Var}(S)$。
   - 二者共同编码"内容保留更强窗口级变化、风格在试次内保持稳定"的无标签软先验。

4. **外部约束**
   - **被试感知对比损失** $L_{con}$：在同被试正样本、跨被试负样本上对比，把风格按被试身份组织；无正样本的锚点被排除（用被试均衡采样器保证六个主数据集每个锚点至少一个同被试正样本）。
   - **重构损失** $L_{rec}$：用样本级风格摘要 $s^*$ 经 FiLM 头生成逐维缩放与偏置（$\lambda, b = g_{film}(s^*)$），重建混合窗口 $\hat{z}_w = \lambda \odot c_w + b$，要求内容分支保留风格摘要无法提供的可重构信息。

5. **总目标**
   $$L = \text{CE}(h_{cls}(C), y) + \lambda_{ord} L_{ord} + \lambda_{sty} L_{sty} + \lambda_{con} L_{con} + \lambda_{rec} L_{rec}$$
   - 被试身份**仅在训练期**用于构建对比对，推理时不需要。

## 6. 主要结论与发现

- **整体提升**：24 个匹配单元中，DEFT 平均提升 B-ACC 0.0460（95% CI [0.0240, 0.0745]），增益跨四个骨干出现。
- **骨干级差异**：平均 B-ACC 增益为 CBraMod +0.0628、CSBrain +0.0574、CodeBrain +0.0425、LaBraM +0.0211（LaBraM 因 Vanilla 起点更强而增益较保守）。
- **任务依赖的组件敏感性**：BCIC-IV-2a、MentalArith.、BCIC-Speech、Mumtaz2016 上消融下降最大；FACED、ISRUC-S1 变化较小。高斯解耦器与方差约束在 BCIC-IV-2a、MentalArith. 上贡献尤为关键。
- **表征几何改善**：内容分支在 6 个数据集中的 5 个提升了被试中心化后的类分离度（如 Mumtaz2016 从 2.291→6.352），BCIC-Speech 略降（0.405→0.307），提示语音线索可能跨通道/窗口局部化，不易体现为全局 PCA 簇。
- **分支功能分化被探测证实**：所有 6 个设置中，内容分支任务探测 B-ACC 更高、风格分支被试探测 B-ACC 更高，支持预期分支组织。
- **对比基线**：在 BCIC-IV-2a、FACED 上优于 GRL、FHVAE-token、DSAE-token、MLP/Attention 因子分解器与参数匹配 Generic Adapter。
- **额外验证**：REVE、OpenNeuro REST、MOMENT/UCI HAR 上均观察到增益，支持方法的可迁移性。

## 7. 优点

- **问题识别有据**：用探测实验明确指出"EFM 嵌入放大被试信息"这一结构性缺陷，动机清晰且有可视化支撑。
- **即插即用、模型无关**：适配器位于骨干之后，只需 EFM 暴露 token 嵌入，参数开销小（约 2.07M，1.55%–10.81%），推理时无需被试身份。
- **方法设计有理论直觉**：递归高斯解耦借鉴卡尔曼滤波/Xi-vector 的精度加权融合，对偶减除与交替精修有明确的推导（Observation 3.1 及附录 D.1）。
- **约束设计互补**：内在时间方差先验（无标签）+ 外部被试对比与重构锚点，形成"内容随任务变、风格随被试稳"的清晰分工。
- **实验严谨性较好**：匹配 checkpoint/划分/骨干策略、保留所有负增益、报告置信区间、包含参数匹配与容量控制以排除混淆因素。
- **可复现性**：公开代码与配置文件，报告数据集许可与使用条款、算力账目与伦理考量。

## 8. 不足与局限

- **先验的强假设**：时间方差先验是任务依赖的软先验，对"被试结构为干扰"的跨被试设置有效，但对特质级或人口统计学目标需重新调节先验强度；论文承认尚未实现完全无监督的解耦微调。
- **需要被试身份**：训练期需被试标签构建对比对；若每个训练被试仅有一个样本，则无同被试正样本，对比损失失效（仅剩分类、方差、重构目标）。
- **超参与损失权重**：引入多个损失权重与先验强度，需在验证集上调参，增加使用成本与过拟合验证集的风险。
- **实验覆盖不均衡**：多种子仅 3 个种子；消融主要在 CBraMod 上，跨骨干组件消融有限；部分结论（递归步数）基于单一数据集。
- **指标级下降未完全解释**：CBraMod-ISRUC-S1 的 Kappa/F1、LaBraM 部分概率指标、CSBrain-Mumtaz2016 B-ACC 等存在下降，虽被保留但归因分析较少。
- **几何指标与性能不一致**：BCIC-Speech 类分离度下降但指标提升，说明该后验几何指标并非总是与解码性能对齐。
- **应用限制**：论文明确 DEFT 不应被视为临床诊断系统，EEG/MDD 数据涉及敏感健康信息，存在隐私与误用风险；单卡 RTX 4090 环境虽经济，但未验证更大规模或更多被试的扩展性。
